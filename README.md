## Langkah Menjalankan Proyek
1. Pastikan Node.js dan Expo Go (di smartphone) sudah terinstal.
2. Buka terminal pada direktori proyek.
3. Jalankan perintah `npm install` untuk memastikan seluruh dependency siap.
4. Jalankan perintah `npx expo start`.
5. Scan QR code yang muncul di terminal menggunakan aplikasi Expo Go.

## Fitur yang Diselesaikan
1. Menampilkan total 5 entri statis pada daftar buku harian.
2. Menggunakan komponen dasar React Native (View, Text, Image, ScrollView, StyleSheet).
3. Memisahkan komponen Ul menjadi *reusable component* pada `src/components/DiaryCard.js`.
4. Menambahkan avatar profil pengguna pada *header*.
5. Mengintegrasikan aset gambar lokal (`happy.png`) pada salah satu entri.
6. Menerapkan variasi warna *border* dinamis pada komponen kartu berdasarkan data.
